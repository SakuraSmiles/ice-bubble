# OpenClaw 数据转换映射

> **文档目的**: 说明如何从 OpenClaw 原始事件格式转换为 UnifiedMessage 格式  
> **更新时间**: 2026-04-08  
> **相关文档**: [OpenClaw-Session数据格式参考.md](./OpenClaw-Session数据格式参考.md)

---

## 📋 转换概述

OpenClaw 原始数据采用事件驱动架构，需要将 5 种事件类型转换为 3 种 UnifiedMessage 类型。

### 事件类型 → 消息类型映射

| OpenClaw 事件类型 | UnifiedMessage 类型 | 说明 |
|------------------|---------------------|------|
| `session` | ❌ 不转换 | 元数据事件，不生成消息 |
| `model_change` | ❌ 不转换 | 配置事件，不生成消息 |
| `thinking_level_change` | ❌ 不转换 | 配置事件，不生成消息 |
| `custom` | ❌ 不转换 | 自定义事件，暂不处理 |
| `message` (role: user) | `user` | 用户消息 |
| `message` (role: assistant) | `agent` | AI 回复 |
| `message` (role: toolResult) | `tool` | 工具结果 |

## 🔄 转换规则详解

### 1. User 消息转换

**原始格式**（OpenClaw MessageEvent）：
```json
{
  "type": "message",
  "id": "bedd2c2c",
  "parentId": "babae8ca",
  "timestamp": "2026-04-03T04:16:30.643Z",
  "message": {
    "role": "user",
    "content": [
      {
        "type": "text",
        "text": "帮我分析错误"
      }
    ],
    "timestamp": 1775189790619
  }
}
```

**转换后**（UnifiedMessage）：
```typescript
{
  id: 'bedd2c2c',                              // 来自 event.id
  sessionKey: 'agent:dev:...:...',            // 从 Session 元数据获取
  messageType: 'user',                        // 固定值
  timestamp: new Date('2026-04-03T04:16:30.643Z'), // 来自 event.timestamp
  source: 'file',                             // 采集器类型
  content: '帮我分析错误',                     // 提取文本内容
  metadata: {
    eventId: 'bedd2c2c',                      // 来自 event.id
    parentId: 'babae8ca',                     // 来自 event.parentId
    contentCount: 1                           // 内容项数量
  },
  raw: { /* 原始事件 JSON */ }
}
```

**转换逻辑**：
```typescript
function convertUserMessage(event: MessageEvent, sessionKey: string): UnifiedMessage {
  // 提取文本内容
  const textContent = event.message.content
    .filter(c => c.type === 'text')
    .map(c => c.text)
    .join('\n');

  return {
    id: event.id,
    sessionKey,
    messageType: 'user',
    timestamp: new Date(event.timestamp),
    source: 'file',
    content: textContent,
    metadata: {
      eventId: event.id,
      parentId: event.parentId,
      contentCount: event.message.content.length
    },
    raw: event
  };
}
```

### 2. Assistant 消息转换

**原始格式**（OpenClaw MessageEvent）：
```json
{
  "type": "message",
  "id": "79381d9b",
  "parentId": "bedd2c2c",
  "timestamp": "2026-04-03T04:16:33.704Z",
  "message": {
    "role": "assistant",
    "content": [
      {
        "type": "thinking",
        "thinking": "Let me start by reading...",
        "thinkingSignature": "22a98a..."
      },
      {
        "type": "toolCall",
        "id": "call_function_okm0dl5ye5bd_1",
        "name": "exec",
        "arguments": {
          "command": "wc -l /path/to/file"
        }
      },
      {
        "type": "text",
        "text": "我来帮你分析"
      }
    ],
    "api": "anthropic-messages",
    "provider": "minimax-cn",
    "model": "MiniMax-M2.7",
    "usage": {
      "input": 36,
      "output": 78,
      "cacheRead": 3580,
      "cacheWrite": 9455,
      "totalTokens": 13149,
      "cost": {
        "input": 0.000018,
        "output": 0.000117,
        "cacheRead": 0,
        "cacheWrite": 0,
        "total": 0.000135
      }
    },
    "stopReason": "toolUse",
    "timestamp": 1775189790642,
    "responseId": "061e721fe126c3448a74f7a585e4e451"
  }
}
```

**转换后**（UnifiedMessage）：
```typescript
{
  id: '79381d9b',
  sessionKey: 'agent:dev:...:...',
  messageType: 'agent',
  timestamp: new Date('2026-04-03T04:16:33.704Z'),
  source: 'file',
  content: '我来帮你分析',                    // 仅提取 text 类型内容
  model: 'MiniMax-M2.7',                      // 来自 message.model
  tokens: {
    input: 36,                                // 来自 message.usage.input
    output: 78                                // 来自 message.usage.output
  },
  tools: [                                    // 提取 toolCall 内容
    {
      name: 'exec',                           // 来自 content[].name
      input: {                                // 来自 content[].arguments
        command: 'wc -l /path/to/file'
      }
    }
  ],
  metadata: {
    eventId: '79381d9b',
    parentId: 'bedd2c2c',
    provider: 'minimax-cn',                   // 来自 message.provider
    api: 'anthropic-messages',                // 来自 message.api
    stopReason: 'toolUse',                    // 来自 message.stopReason
    responseId: '061e721fe126c3448a74f7a585e4e451',
    thinkingIncluded: true,                   // 是否包含 thinking 内容
    contentTypes: ['thinking', 'toolCall', 'text'], // 内容类型列表
    totalTokens: 13149,                       // 来自 message.usage.totalTokens
    cost: 0.000135                            // 来自 message.usage.cost.total
  },
  raw: { /* 原始事件 JSON */ }
}
```

**转换逻辑**：
```typescript
function convertAssistantMessage(event: MessageEvent, sessionKey: string): UnifiedMessage {
  const message = event.message;
  
  // 提取文本内容（仅 text 类型）
  const textContent = message.content
    .filter(c => c.type === 'text')
    .map(c => c.text)
    .join('\n');

  // 提取工具调用
  const tools: ToolCall[] = message.content
    .filter(c => c.type === 'toolCall')
    .map(c => ({
      name: c.name,
      input: c.arguments,
      result: undefined // toolCall 中没有 result
    }));

  return {
    id: event.id,
    sessionKey,
    messageType: 'agent',
    timestamp: new Date(event.timestamp),
    source: 'file',
    content: textContent,
    model: message.model,
    tokens: message.usage ? {
      input: message.usage.input,
      output: message.usage.output
    } : undefined,
    tools: tools.length > 0 ? tools : undefined,
    metadata: {
      eventId: event.id,
      parentId: event.parentId,
      provider: message.provider,
      api: message.api,
      stopReason: message.stopReason,
      responseId: message.responseId,
      thinkingIncluded: message.content.some(c => c.type === 'thinking'),
      contentTypes: message.content.map(c => c.type),
      totalTokens: message.usage?.totalTokens,
      cost: message.usage?.cost.total
    },
    raw: event
  };
}
```

### 3. ToolResult 消息转换

**原始格式**（OpenClaw MessageEvent）：
```json
{
  "type": "message",
  "id": "f04ed3dc",
  "parentId": "79381d9b",
  "timestamp": "2026-04-03T04:16:33.969Z",
  "message": {
    "role": "toolResult",
    "toolCallId": "call_function_okm0dl5ye5bd_1",
    "toolName": "exec",
    "content": [
      {
        "type": "text",
        "text": "Approval required (id bc5f3f08...)"
      }
    ],
    "details": {
      "status": "approval-pending",
      "approvalId": "bc5f3f08-2378-4069-a0e5-17e3a1f6522a",
      "approvalSlug": "bc5f3f08",
      "expiresAtMs": 1775191593955,
      "host": "gateway",
      "command": "wc -l /path/to/file",
      "cwd": "/home/dabai/.openclaw/workspace/dev/config",
      "warningText": ""
    },
    "isError": false,
    "timestamp": 1775189793956
  }
}
```

**转换后**（UnifiedMessage）：
```typescript
{
  id: 'f04ed3dc',
  sessionKey: 'agent:dev:...:...',
  messageType: 'tool',
  timestamp: new Date('2026-04-03T04:16:33.969Z'),
  source: 'file',
  content: 'Approval required (id bc5f3f08...)', // 提取文本内容
  tools: [
    {
      name: 'exec',                           // 来自 message.toolName
      input: undefined,                       // toolResult 没有 input
      result: {                               // 构造结果对象
        status: 'approval-pending',
        approvalId: 'bc5f3f08-2378-4069-a0e5-17e3a1f6522a',
        output: 'Approval required (id bc5f3f08...)'
      },
      durationMs: undefined                   // 来自 message.details.durationMs
    }
  ],
  metadata: {
    eventId: 'f04ed3dc',
    parentId: '79381d9b',
    toolCallId: 'call_function_okm0dl5ye5bd_1', // 来自 message.toolCallId
    isError: false,                           // 来自 message.isError
    status: 'approval-pending',               // 来自 message.details.status
    exitCode: undefined,                      // 来自 message.details.exitCode
    durationMs: undefined,                    // 来自 message.details.durationMs
    cwd: '/home/dabai/.openclaw/workspace/dev/config', // 来自 message.details.cwd
    // Approval 相关字段
    approval: {
      id: 'bc5f3f08-2378-4069-a0e5-17e3a1f6522a',
      slug: 'bc5f3f08',
      command: 'wc -l /path/to/file',
      expiresAt: new Date(1775191593955)
    }
  },
  raw: { /* 原始事件 JSON */ }
}
```

**转换逻辑**：
```typescript
function convertToolResultMessage(event: MessageEvent, sessionKey: string): UnifiedMessage {
  const message = event.message;
  
  // 提取文本内容
  const textContent = message.content
    .filter(c => c.type === 'text')
    .map(c => c.text)
    .join('\n');

  // 构造工具结果
  const tools: ToolCall[] = [{
    name: message.toolName!,
    input: undefined,
    result: {
      status: message.details?.status,
      approvalId: message.details?.approvalId,
      output: textContent
    },
    durationMs: message.details?.durationMs
  }];

  return {
    id: event.id,
    sessionKey,
    messageType: 'tool',
    timestamp: new Date(event.timestamp),
    source: 'file',
    content: textContent,
    tools,
    metadata: {
      eventId: event.id,
      parentId: event.parentId,
      toolCallId: message.toolCallId,
      isError: message.isError,
      status: message.details?.status,
      exitCode: message.details?.exitCode,
      durationMs: message.details?.durationMs,
      cwd: message.details?.cwd,
      // Approval 相关
      approval: message.details?.status === 'approval-pending' ? {
        id: message.details.approvalId,
        slug: message.details.approvalSlug,
        command: message.details.command,
        expiresAt: new Date(message.details.expiresAtMs!)
      } : undefined
    },
    raw: event
  };
}
```

## 📊 SessionKey 构造规则

SessionKey 需要从 Session 元数据事件中提取：

**原始格式**（SessionEvent）：
```json
{
  "type": "session",
  "version": 3,
  "id": "012582c0-3fc5-4a35-818c-0dd9a1c359d4",
  "timestamp": "2026-04-03T04:16:30.616Z",
  "cwd": "/home/dabai/.openclaw/workspace/dev/config"
}
```

**构造逻辑**：
```typescript
function buildSessionKey(sessionEvent: SessionEvent): string {
  // 从 cwd 解析信息
  // cwd: "/home/dabai/.openclaw/workspace/dev/config"
  // 提取 agentId: "dev"
  
  const cwdParts = sessionEvent.cwd.split('/');
  const workspaceIndex = cwdParts.findIndex(p => p === 'workspace');
  const agentId = workspaceIndex >= 0 ? cwdParts[workspaceIndex + 1] : 'unknown';
  
  // OpenClaw 本地模式下的 SessionKey 格式
  return `agent:${agentId}:local:default:direct:${sessionEvent.id}`;
}
```

**SessionKey 格式**：
```
agent:{agentId}:{channel}:{accountId}:{type}:{targetId}

示例：
- agent:dev:local:default:direct:012582c0-3fc5-4a35-818c-0dd9a1c359d4
- agent:prod:discord:acc-123:direct:peer-456
```

## 🚫 不转换的事件类型

以下事件类型不会生成 UnifiedMessage，但需要记录元数据：

### 1. Session 元数据事件
- **用途**: 提取 SessionKey
- **存储**: sessions 表
- **不生成**: UnifiedMessage

### 2. Model Change 事件
- **用途**: 记录模型变更
- **存储**: 可以存储到单独的表（可选）
- **不生成**: UnifiedMessage

### 3. Thinking Level Change 事件
- **用途**: 记录思考级别变更
- **存储**: 可以存储到单独的表（可选）
- **不生成**: UnifiedMessage

### 4. Custom 事件
- **用途**: 自定义事件（如 model-snapshot）
- **存储**: 暂不处理
- **不生成**: UnifiedMessage

## 🔧 转换工具函数

### 统一转换入口

```typescript
/**
 * 将 OpenClaw 事件转换为 UnifiedMessage
 */
export function convertOpenClawEvent(
  event: OpenClawEvent,
  sessionKey: string
): UnifiedMessage | null {
  // 只处理 MessageEvent
  if (event.type !== 'message') {
    return null;
  }

  const messageEvent = event as MessageEvent;
  
  switch (messageEvent.message.role) {
    case 'user':
      return convertUserMessage(messageEvent, sessionKey);
    
    case 'assistant':
      return convertAssistantMessage(messageEvent, sessionKey);
    
    case 'toolResult':
      return convertToolResultMessage(messageEvent, sessionKey);
    
    default:
      console.warn(`Unknown message role: ${messageEvent.message.role}`);
      return null;
  }
}
```

## 📝 注意事项

### 1. 内容提取规则
- **只提取 text 类型**的内容作为 `content` 字段
- **thinking 内容**不放入 `content`，但记录在 `metadata.thinkingIncluded`
- **toolCall 内容**提取到 `tools` 数组

### 2. Token 统计
- **UnifiedMessage 只保留 input/output**，其他信息放入 metadata
- **cost 信息**放入 `metadata.cost`

### 3. 工具调用
- **assistant 消息**中的 toolCall 只提取 name 和 input
- **toolResult 消息**构造完整的 result 对象

### 4. 元数据保留
- **原始 JSON** 保留在 `raw` 字段，用于调试和扩展
- **所有重要字段**都提取到 `metadata`，避免丢失信息
