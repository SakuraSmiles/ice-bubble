## 项目背景与目标

### 业务背景

OpenClaw 是一个多 Agent 协同系统,运行过程中会产生大量有价值的数据:
- Agent 配置信息和运行状态
- Session 对话历史和工具调用
- Token 消耗和性能指标

这些数据分散在不同存储介质中,缺乏统一的采集和监控能力。

### 项目目标

开发 **ice-bubble-collector-openclaw** 模块,实现:

1. **数据采集**: 实时采集 OpenClaw 的核心业务数据
2. **数据存储**: 持久化存储到本地数据库,支持复杂查询
3. **实时推送**: 提供实时数据订阅能力,支持下游服务消费
4. **高可用保障**: 多通道采集机制,确保数据完整性

### 核心需求优先级

| 优先级 | 需求 | 说明 |
|--------|------|------|
| **P0** | Session 数据采集 | 完整对话历史、工具调用、Token 统计 |
| **P1** | Agent 状态监控 | 在线状态、配置变更、健康检查 |
| **P2** | 性能指标采集 | 响应时间、消息量趋势、错误率 |

## 数据源分析

### 1. WebSocket Gateway

**连接地址**: `wss://gateway:18789`

**认证方式**:
```json
{
  "type": "req",
  "id": "connect-001",
  "method": "connect",
  "params": {
    "role": "operator",
    "scopes": ["operator.read"],
    "auth": { "token": "your-openclaw-token" }
  }
}
```

**可订阅事件**:

| 事件类型 | 方法 | 数据内容 | 实时性 |
|---------|------|---------|--------|
| `session.message` | `sessions.messages.subscribe` | 会话新消息 | < 100ms |
| `session.tool` | `sessions.messages.subscribe` | 工具调用事件 | < 100ms |
| `sessions.changed` | `sessions.subscribe` | 会话列表变更 | < 100ms |
| `presence` | 自动推送 | Agent 在线状态 | 实时 |
| `health` | 自动推送 | Gateway 健康状态 | 心跳周期 |

**优势**:
- ✅ 实时性强,毫秒级延迟
- ✅ OpenClaw 主动推送,性能影响小
- ✅ 支持流式数据,无需轮询

**劣势**:
- ❌ 需要维护持久连接
- ❌ 断线期间可能丢失数据
- ❌ 需要实现重连和补偿机制

---

### 2. 文件系统

**存储路径**: `~/.openclaw/agents/<agentId>/sessions/*.jsonl`

**Session Key 格式**:
```
agent:{agentId}:{channel}:{accountId}:direct:{peerId}  // 私聊
agent:{agentId}:{channel}:{accountId}:guild:{guildId}  // 群聊
```

**文件格式** (JSON Lines):
```jsonl
{"type":"user","text":"帮我分析错误","timestamp":"2026-04-08T10:00:00Z"}
{"type":"agent","text":"我看到错误...","model":"claude-3-5-sonnet","tokens":{"input":150,"output":300},"tools":[{"name":"code_analyzer","result":"..."}]}
{"type":"tool","name":"code_analyzer","input":{...},"result":{...},"timestamp":"2026-04-08T10:00:05Z"}
```

**数据内容**:
- 用户消息和 AI 回复
- 工具调用和返回结果
- Token 统计信息
- 时间戳和元数据

**优势**:
- ✅ 数据最完整,包含所有历史记录
- ✅ 性能影响极低,只读文件
- ✅ 支持离线处理和历史回溯

**劣势**:
- ❌ 实时性较差 (文件刷新周期 1-5s)
- ❌ 需要文件系统访问权限
- ❌ 需要实现增量读取和断点续传

### 3. HTTP API

**端点列表**:

| 端点 | 方法 | 数据内容 | 响应时间 |
|-----|------|---------|---------|
| `/v1/sessions` | GET | Session 列表和元数据 | ~50ms |
| `/v1/sessions/{key}/messages` | GET | Session 消息历史 | ~100ms |
| `/v1/channels` | GET | Channel 列表 | ~50ms |
| `/v1/guilds` | GET | Guild 列表 | ~50ms |
| `/status` | GET | Gateway 健康状态 | ~20ms |

**查询参数支持**:
- `since=<timestamp>`: 增量查询指定时间后的数据
- `limit=<n>`: 限制返回数量
- `offset=<n>`: 分页偏移

**优势**:
- ✅ 实现最简单,标准 HTTP 请求
- ✅ 无需维护长连接,无状态
- ✅ 支持远程访问 (不需要同一台机器)
- ✅ 支持增量查询

**劣势**:
- ❌ 实时性差,取决于轮询间隔
- ❌ 频繁轮询增加 OpenClaw 负载
- ❌ 无法获取实时推送事件

### 数据流转流程

```
1. 数据采集 (WebSocket/File/HTTP)
     ↓
2. 数据验证 (格式校验、完整性检查)
     ↓
3. 去重检查 (Redis LRU 缓存)
     ↓
4. 异步队列 (BlockingQueue)
     ↓
5. 批量写入 (每 100 条或 5 秒)
     ↓
6. SQLite 持久化存储
     ↓
7. Redis 缓存更新 (实时状态、最新消息)
     ↓
8. WebSocket Pub/Sub 推送给下游服务
```

#### WebSocketCollector

```typescript
import WebSocket from 'ws';
import { EventEmitter } from 'events';

class WebSocketCollector extends EventEmitter {
    private client: WebSocket | null = null;
    private queue: MessageQueue;
    private deduplicator: Deduplicator;
    private reconnectInterval: number = 5000;
    
    constructor(queue: MessageQueue, deduplicator: Deduplicator) {
        super();
        this.queue = queue;
        this.deduplicator = deduplicator;
    }
    
    // 连接到 OpenClaw Gateway
    async connect(url: string, token: string): Promise<void> {
        return new Promise((resolve, reject) => {
            this.client = new WebSocket(url, {
                headers: { 'Authorization': `Bearer ${token}` }
            });
            
            this.client.on('open', () => {
                console.log('WebSocket connected');
                this.emit('connected');
                resolve();
            });
            
            this.client.on('message', (data: Buffer) => {
                this.handleMessage(data);
            });
            
            this.client.on('close', () => {
                console.log('WebSocket disconnected, reconnecting...');
                setTimeout(() => this.connect(url, token), this.reconnectInterval);
            });
            
            this.client.on('error', (error) => {
                console.error('WebSocket error:', error);
                reject(error);
            });
        });
    }
    
    // 订阅事件
    subscribe(method: string, params: Record<string, any>): void {
        const message = {
            type: 'req',
            id: `sub-${Date.now()}`,
            method,
            params
        };
        
        this.client?.send(JSON.stringify(message));
    }
    
    // 处理推送事件
    private async handleMessage(data: Buffer): Promise<void> {
        try {
            const event = JSON.parse(data.toString());
            
            // 1. 数据验证
            if (!this.validateEvent(event)) return;
            
            // 2. 去重检查
            const key = this.generateKey(event);
            if (await this.deduplicator.exists(key)) return;
            
            // 3. 加入异步队列
            this.queue.push(event);
            
            // 4. 标记已处理
            await this.deduplicator.mark(key);
        } catch (error) {
            console.error('Handle message error:', error);
        }
    }
    
    private validateEvent(event: any): boolean {
        return event && event.payload;
    }
    
    private generateKey(event: any): string {
        return `${event.payload.sessionKey}:${event.payload.timestamp}:${event.type}`;
    }
    
    // 断开连接
    disconnect(): void {
        this.client?.close();
        this.client = null;
    }
}
```

#### FileCollector

```typescript
import chokidar from 'chokidar';
import fs from 'fs-extra';
import readline from 'readline';
import { EventEmitter } from 'events';

class FileCollector extends EventEmitter {
    private watcher: chokidar.FSWatcher | null = null;
    private positionTracker: PositionTracker;
    private queue: MessageQueue;
    private basePath: string;
    
    constructor(basePath: string, queue: MessageQueue, positionTracker: PositionTracker) {
        super();
        this.basePath = basePath;
        this.queue = queue;
        this.positionTracker = positionTracker;
    }
    
    // 监听文件变更
    watch(): void {
        this.watcher = chokidar.watch(`${this.basePath}/**/*.jsonl`, {
            ignored: /(^|[\/\\])\../, // 忽略隐藏文件
            persistent: true,
            ignoreInitial: false,
            awaitWriteFinish: {
                stabilityThreshold: 2000,
                pollInterval: 100
            }
        });
        
        this.watcher.on('change', async (filePath: string) => {
            await this.handleFileChange(filePath);
        });
        
        this.watcher.on('add', async (filePath: string) => {
            await this.handleFileChange(filePath);
        });
        
        console.log(`Watching files in ${this.basePath}`);
    }
    
    // 处理文件变更
    private async handleFileChange(filePath: string): Promise<void> {
        try {
            // 增量读取新增行
            const lastPosition = await this.positionTracker.getPosition(filePath);
            const newLines = await this.readFromLine(filePath, lastPosition);
            
            // 解析并加入队列
            for (const line of newLines.lines) {
                try {
                    const message = JSON.parse(line);
                    this.queue.push(message);
                } catch (error) {
                    console.error(`Failed to parse line: ${line}`, error);
                }
            }
            
            // 更新读取位置
            await this.positionTracker.savePosition(filePath, newLines.endPosition);
        } catch (error) {
            console.error(`Error handling file change: ${filePath}`, error);
        }
    }
    
    // 从指定位置读取新增行
    private async readFromLine(filePath: string, startPosition: number): Promise<{
        lines: string[],
        endPosition: number
    }> {
        const fileStream = fs.createReadStream(filePath, {
            start: startPosition,
            encoding: 'utf-8'
        });
        
        const rl = readline.createInterface({
            input: fileStream,
            crlfDelay: Infinity
        });
        
        const lines: string[] = [];
        let endPosition = startPosition;
        
        for await (const line of rl) {
            if (line.trim()) {
                lines.push(line);
                endPosition += Buffer.byteLength(line, 'utf-8') + 1;
            }
        }
        
        return { lines, endPosition };
    }
    
    // 停止监听
    stop(): void {
        this.watcher?.close();
        this.watcher = null;
    }
}
```

#### HTTPCollector

```typescript
import axios, { AxiosInstance } from 'axios';
import { EventEmitter } from 'events';
import cron from 'node-cron';

class HTTPCollector extends EventEmitter {
    private client: AxiosInstance;
    private baseUrl: string;
    private token: string;
    
    constructor(baseUrl: string, token: string) {
        super();
        this.baseUrl = baseUrl;
        this.token = token;
        this.client = axios.create({
            baseURL: baseUrl,
            headers: { 'Authorization': `Bearer ${token}` },
            timeout: 30000
        });
    }
    
    // 全量同步 (每天 2AM)
    startFullSync(): void {
        cron.schedule('0 2 * * *', async () => {
            console.log('Starting full sync...');
            await this.fullSync();
        });
    }
    
    // 执行全量同步
    async fullSync(): Promise<void> {
        try {
            const response = await this.client.get('/v1/sessions');
            const sessions = response.data;
            
            console.log(`Found ${sessions.length} sessions to sync`);
            
            for (const session of sessions) {
                await this.syncSessionMessages(session.key);
            }
            
            console.log('Full sync completed');
        } catch (error) {
            console.error('Full sync failed:', error);
            this.emit('error', error);
        }
    }
    
    // 同步单个 Session 的消息
    private async syncSessionMessages(sessionKey: string): Promise<void> {
        try {
            const response = await this.client.get(
                `/v1/sessions/${encodeURIComponent(sessionKey)}/messages`
            );
            
            const messages = response.data;
            this.emit('messages', { sessionKey, messages });
        } catch (error) {
            console.error(`Failed to sync session ${sessionKey}:`, error);
        }
    }
    
    // 手动触发全量同步
    async triggerFullSync(): Promise<void> {
        await this.fullSync();
```

#### Deduplicator (去重机制)

```typescript
import Redis from 'ioredis';

class Deduplicator {
    private redis: Redis;
    private readonly MAX_CACHE_SIZE: number = 10000;
    private readonly DEDUP_KEY = 'dedup:messages';
    
    constructor(redis: Redis) {
        this.redis = redis;
    }
    
    // 检查是否已存在
    async exists(key: string): Promise<boolean> {
        const result = await this.redis.sismember(this.DEDUP_KEY, key);
        return result === 1;
    }
    
    // 添加到缓存
    async mark(key: string): Promise<void> {
        await this.redis.sadd(this.DEDUP_KEY, key);
        
        // LRU 淘汰机制
        const size = await this.redis.scard(this.DEDUP_KEY);
        if (size > this.MAX_CACHE_SIZE) {
            const removeCount = size - this.MAX_CACHE_SIZE + 100;
            const members = await this.redis.srandmember(this.DEDUP_KEY, removeCount);
            if (members.length > 0) {
                await this.redis.srem(this.DEDUP_KEY, ...members);
            }
        }
    }
}
```

```typescript
import { EventEmitter } from 'events';

class BatchWriter extends EventEmitter {
    private queue: OpenClawMessage[] = [];
    private db: SQLiteManager;
    private readonly BATCH_SIZE: number = 100;
    private readonly FLUSH_INTERVAL: number = 5000; // 5秒
    private flushTimer: NodeJS.Timeout | null = null;
    
    constructor(db: SQLiteManager) {
        super();
        this.db = db;
    }
    
    // 启动批量写入器
    start(): void {
        this.startFlushTimer();
    }
    
    // 添加消息到队列
    push(message: OpenClawMessage): void {
        this.queue.push(message);
        
        // 达到批量大小立即刷新
        if (this.queue.length >= this.BATCH_SIZE) {
            this.flush();
        }
    }
    
    // 刷新队列数据到数据库
    private async flush(): Promise<void> {
        if (this.queue.length === 0) return;
        
        const batch = this.queue.splice(0, this.BATCH_SIZE);
        
        try {
            await this.db.batchInsert(batch);
            this.emit('flushed', { count: batch.length });
        } catch (error) {
            console.error('Batch insert failed:', error);
            this.queue.unshift(...batch);
        }
    }
    
    // 获取队列大小
    getQueueSize(): number {
        return this.queue.length;
    }
}
```

```typescript
import sqlite3 from 'sqlite3';

class SQLiteAdapter {
    private db: Database | null = null;
    private dbPath: string;
    
    constructor(dbPath: string) {
        this.dbPath = dbPath;
    }
    
    // 初始化数据库连接
    async init(): Promise<void> {
        this.db = await open({
            filename: this.dbPath,
            driver: sqlite3.Database
        });
        
        await this.createTables();
    }
    
    // 批量插入消息
    async batchInsert(messages: OpenClawMessage[]): Promise<void> {
        const sql = `INSERT INTO session_messages 
                     (session_key, message_type, content, timestamp) 
                     VALUES (?, ?, ?, ?)`;
        
        await this.db!.exec('BEGIN TRANSACTION');
        
        try {
            for (const msg of messages) {
                await this.db!.run(sql, [
                    msg.sessionKey,
                    msg.type,
                    msg.content,
                    new Date(msg.timestamp).toISOString()
                ]);
            }
            await this.db!.exec('COMMIT');
        } catch (error) {
            await this.db!.exec('ROLLBACK');
            throw error;
        }
    }
    
    // 查询 Session 历史
    async getSessionHistory(sessionKey: string, limit: number = 100): Promise<any[]> {
        const sql = `SELECT * FROM session_messages 
                     WHERE session_key = ? 
                     ORDER BY timestamp DESC 
                     LIMIT ?`;
        
        return await this.db!.all(sql, [sessionKey, limit]);
    }
}
```

```typescript
    }

    async acquireLock(lockKey: string, ttl: number = 10000): Promise<boolean> {
        const key = `lock:collection:${lockKey}`;
        const value = `${Date.now()}:${Math.random()}`;
        const result = await this.redis.set(key, value, 'PX', ttl, 'NX');
        return result === 'OK';
    }
```

## 性能优化策略

### 1. 批量写入优化

```
优化前: 每条消息立即写入数据库
  → 性能: ~100 TPS

优化后: 每 100 条或 5 秒批量写入
  → 性能: ~5000 TPS
  → 提升: 50 倍
```

### 2. 增量读取优化

```
优化前: 每次全量解析整个 .jsonl 文件
  → 性能: 解析 1MB 文件 ~500ms

优化后: 记录已读取位置,增量读取新增行
  → 性能: 解析新增数据 ~5ms
  → 提升: 100 倍
```

### 3. 去重缓存优化

```
优化前: 每条消息查询数据库判断重复
  → 性能: ~50 TPS

优化后: Redis LRU 缓存最近 1 万条消息 ID
  → 性能: ~5000 TPS
  → 提升: 100 倍
```
