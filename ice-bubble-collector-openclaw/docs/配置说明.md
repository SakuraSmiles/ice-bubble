# 配置说明

## 📋 概述

`ice-bubble-collector-openclaw` 采用**配置文件优先**的设计理念，所有配置均通过配置文件管理。

### 配置优先级

```
config/config.json > 默认配置
```

**重要说明**：
- ✅ 配置文件是**唯一配置源**
- ❌ **不支持**环境变量覆盖
- ✅ 配置集中管理，清晰明了

---

## 📂 配置文件位置

```
config/
├── config.json              # ✅ 用户创建的主配置（最高优先级）
├── config.example.json      # ✅ 完整配置模板
├── config.development.json  # 开发环境示例
└── config.production.json   # 生产环境示例
```

---

## 🚀 快速开始

### 1. 创建配置文件

```bash
# 复制配置模板
cp config/config.example.json config/config.json
```

### 2. 编辑配置

```bash
# 编辑配置文件
vim config/config.json
```

### 3. 启动服务

```bash
# 自动加载 config/config.json
npm start
```

## ⚙️ 配置文件说明

### 核心配置（必填）

#### 1. OpenClaw 数据目录

```json
{
  "openclaw": {
    "dataDir": "~/.openclaw"
  }
}
```

**说明**：
- OpenClaw 数据根目录
- 支持 `~` 符号（自动展开为用户主目录）
- 支持相对路径和绝对路径

**示例**：
- Windows: `"C:/Users/dabai/.openclaw"`
- Linux: `"/var/lib/openclaw"`
- macOS: `"~/.openclaw"`

---

#### 2. SQLite 数据库路径

```json
{
  "storage": {
    "sqlite": {
      "dbPath": "./data/collector.db",
      "walMode": true
    }
  }
}
```

**说明**：
- SQLite 数据库文件路径
- `walMode`: 启用 WAL 模式，提升写入性能
- 数据库文件会自动创建

**示例**：
- 开发环境: `"./data/collector-dev.db"`
- 生产环境: `"/var/lib/collector/collector.db"`

---

#### 3. 文件监听路径

```json
{
  "collection": {
    "file": {
      "watchPath": "~/.openclaw/agents",
      "enableWatch": true
    }
  }
}
```

**说明**：
- OpenClaw Session 文件目录
- 系统会自动扫描：`{watchPath}/*/sessions/*.jsonl`
- `enableWatch`: 启用实时文件监听

**扫描规则**：
```
{watchPath}/
├── agent-1/
│   └── sessions/
│       ├── session-001.jsonl  ✅ 会被扫描
│       └── session-002.jsonl  ✅ 会被扫描
└── agent-2/
    └── sessions/
        └── session-003.jsonl  ✅ 会被扫描
```

## 🌍 环境配置

### 开发环境配置

使用 `config.development.json` 作为参考：

```bash
# 1. 复制开发环境配置
cp config/config.development.json config/config.json

# 2. 启动开发环境
npm run dev
```

**开发环境特点**：
- 日志级别: `debug`
- 数据库: `./data/collector-dev.db`
- 批量大小: 50（便于测试）
- API: 关闭（减少资源占用）

---

### 生产环境配置

使用 `config.production.json` 作为参考：

```bash
# 1. 复制生产环境配置
cp config/config.production.json config/config.json

# 2. 修改关键配置
vim config/config.json

# 3. 启动生产环境
npm start
```

**生产环境特点**：
- 日志级别: `warn`
- 数据库: `/var/lib/collector/collector.db`
- 批量大小: 100（提升性能）
- API: 开启（提供查询接口）
- Redis: 开启（缓存和去重）

## ⚠️ 重要注意事项

### 1. 配置文件安全

**不要提交 config.json 到 Git**：

```gitignore
# .gitignore
config/config.json
config/config.production.json
```

**敏感信息**：
- Token 应该直接写入配置文件
- 定期更换 Token
- 限制配置文件访问权限

---

### 2. 路径配置建议

#### ✅ 推荐

```json
{
  "openclaw": {
    "dataDir": "~/.openclaw"  // 使用 ~ 符号
  },
  "storage": {
    "sqlite": {
      "dbPath": "/var/lib/collector/collector.db"  // 使用绝对路径
    }
  }
}
```

#### ❌ 不推荐

```json
{
  "storage": {
    "sqlite": {
      "dbPath": "data/collector.db"  // 相对路径，容易出错
    }
  }
}
```

---

### 3. 性能调优

#### 批量写入优化

```json
{
  "processing": {
    "batchWriter": {
      "batchSize": 100,        // 批量大小（越大性能越好，但内存占用越高）
      "flushInterval": 5000    // 刷新间隔（毫秒）
    }
  }
}
```

**建议**：
- 开发环境: `batchSize: 50`
- 生产环境: `batchSize: 100-200`

---

#### 去重缓存优化

```json
{
  "processing": {
    "deduplicator": {
      "cacheSize": 10000,      // 缓存最近 10000 条消息 ID
      "ttl": 86400000          // 缓存有效期：24 小时
    }
  }
}
```

**建议**：
- 高频场景: `cacheSize: 20000`
- 低频场景: `cacheSize: 5000`

---

### 4. 数据库维护

#### 定期备份

```json
{
  "backup": {
    "enabled": true,
    "schedule": "0 2 * * *",   // 每天 2:00 AM 备份
    "retention": 7,            // 保留最近 7 天备份
    "path": "./backups"
  }
}
```

#### 数据库大小估算

| 消息数量 | 数据库大小 |
|---------|----------|
| 10 万条 | ~110MB   |
| 50 万条 | ~550MB   |
| 100 万条| ~1.1GB   |

**建议**：预留至少 **10GB** 磁盘空间

## 📚 常见问题

### Q1: 如何修改配置？

**A**: 直接编辑 `config/config.json`，重启服务即可生效。

---

### Q2: 配置文件不存在会怎样？

**A**: 系统会使用默认配置启动，并提示创建配置文件：

```bash
[ConfigLoader] 配置文件不存在: config/config.json，使用默认配置
[ConfigLoader] 请创建配置文件: cp config/config.example.json config/config.json
```

---

### Q3: 如何查看当前配置？

**A**: 启动时会打印配置信息：

```bash
[ConfigLoader] 配置文件加载成功: config/config.json
[ConfigLoader] OpenClaw 数据目录: /Users/dabai/.openclaw
[ConfigLoader] 数据库路径: /var/lib/collector/collector.db
[ConfigLoader] 文件监听路径: /Users/dabai/.openclaw/agents
```

---

### Q4: 配置文件支持 YAML 格式吗？

**A**: 支持，需要安装 `js-yaml`：

```bash
npm install js-yaml
```

然后使用 `config/config.yaml` 或 `config/config.yml`。
